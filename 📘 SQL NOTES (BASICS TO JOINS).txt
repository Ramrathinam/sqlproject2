📘 SQL NOTES (BASICS TO JOINS)
1️⃣ What is SQL?

SQL (Structured Query Language) is used to:

Store data

Retrieve data

Update data

Delete data

Manage database structure

2️⃣ Types of SQL Commands
🔹 DDL (Data Definition Language)

Used to change table structure.

CREATE

ALTER

DROP

TRUNCATE

Example:

CREATE TABLE students (
    sid INT PRIMARY KEY,
    name VARCHAR(50)
);
🔹 DML (Data Manipulation Language)

Used to manipulate data.

INSERT

UPDATE

DELETE

Example:

INSERT INTO students VALUES (1, 'Ram');
🔹 DQL (Data Query Language)

Used to fetch data.

SELECT

Example:

SELECT * FROM students;
3️⃣ SELECT Statement

Basic syntax:

SELECT column_name
FROM table_name;

Select all columns:

SELECT * FROM students;
4️⃣ WHERE Clause

Used to filter rows.

SELECT * FROM students
WHERE sid = 1;
Operators:

=

!= or <>

<

=

<=

AND

OR

IN

BETWEEN

LIKE

Example:

SELECT * FROM students
WHERE name LIKE 'R%';
5️⃣ GROUP BY

Used to group rows having same values.

Example:

SELECT sid, SUM(amount)
FROM payments
GROUP BY sid;

Important Rule:
If you use SUM, COUNT, AVG → use GROUP BY.

6️⃣ HAVING

Used to filter grouped results.

Example:

SELECT sid, SUM(amount)
FROM payments
GROUP BY sid
HAVING SUM(amount) > 2000;

Difference:

WHERE → filters rows

HAVING → filters grouped data

7️⃣ ORDER BY

Used to sort results.

SELECT * FROM students
ORDER BY name ASC;

DESC → descending order

8️⃣ Keys in SQL
🔹 Primary Key

Unique

Cannot be NULL

Identifies each row

Example:

sid INT PRIMARY KEY
🔹 Foreign Key

Creates relationship between tables

References primary key of another table

Example:

FOREIGN KEY (sid) REFERENCES courses(sid)
9️⃣ What is JOIN?

JOIN is used to combine rows from two or more tables based on a related column.

General syntax:

SELECT columns
FROM table1
JOIN table2
ON table1.column = table2.column;
🔵 1. INNER JOIN

Returns only matching rows from both tables.

SELECT s.name, c.course
FROM students s
INNER JOIN courses c
ON s.sid = c.sid;

Only common values appear.

🟢 2. LEFT JOIN

Returns:

All rows from left table

Matching rows from right table

If no match → NULL

SELECT s.name, c.course
FROM students s
LEFT JOIN courses c
ON s.sid = c.sid;
🟡 3. RIGHT JOIN

Returns:

All rows from right table

Matching rows from left table

If no match → NULL

SELECT s.name, c.course
FROM students s
RIGHT JOIN courses c
ON s.sid = c.sid;
🔴 4. CROSS JOIN

Returns all possible combinations.

SELECT s.name, c.course
FROM students s
CROSS JOIN courses c;

Rows = rows(table1) × rows(table2)

🔟 Important Concepts
WHERE vs HAVING

WHERE → before grouping

HAVING → after grouping

INNER vs LEFT

INNER → only matching

LEFT → keep all left

JOIN vs Foreign Key

Foreign Key → maintains relationship

JOIN → retrieves combined data

🔥 Final Understanding

JOIN works based on:

ON table1.column = table2.column

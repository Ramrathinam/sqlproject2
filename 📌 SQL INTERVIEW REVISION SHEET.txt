🔹 3️⃣ Important WHERE Operators

=

<> or !=

< >= <=

AND / OR

IN

BETWEEN

LIKE

IS NULL

Example:

WHERE salary BETWEEN 30000 AND 60000
WHERE name LIKE 'R%'
🔹 4️⃣ GROUP BY + Aggregate Functions

Aggregate functions:

SUM()

COUNT()

AVG()

MAX()

MIN()

SELECT dept, SUM(salary)
FROM workers
GROUP BY dept;

Important:
👉 Every non-aggregate column must be in GROUP BY.

🔹 5️⃣ HAVING

Filters grouped data.

SELECT dept, AVG(salary)
FROM workers
GROUP BY dept
HAVING AVG(salary) > 50000;

Difference:

WHERE → before grouping

HAVING → after grouping

🔹 6️⃣ ORDER BY
ORDER BY salary DESC;

DESC → descending

🔹 8️⃣ JOIN Quick Revision

General syntax:

SELECT columns
FROM table1
JOIN table2
ON table1.col = table2.col;
INNER JOIN

Only matching rows.

LEFT JOIN

All left rows + matching right.

RIGHT JOIN

All right rows + matching left.

CROSS JOIN

All combinations.

🔹 9️⃣ Subquery

Query inside query.

SELECT *
FROM workers
WHERE salary > (SELECT AVG(salary) FROM workers);
🔹 🔟 UPDATE / DELETE

Update:

UPDATE workers
SET salary = 50000
WHERE emp_id = 1;

Delete:

DELETE FROM workers
WHERE emp_id = 1;
🔹 1️⃣1️⃣ DELETE vs TRUNCATE vs DROP

DELETE

Removes specific rows

Uses WHERE

Can rollback

TRUNCATE

Removes all rows

Faster

Cannot use WHERE

DROP

Deletes entire table

🔹 1️⃣2️⃣ NULL Handling

Check NULL:

WHERE column IS NULL;

Not:

WHERE column = NULL; ❌
